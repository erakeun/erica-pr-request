보도자료용 사진 선택사항

사진을 선택하면 원본이 한 장씩 임시 Drive 폴더에 먼저 업로드됩니다.
사진 파일은 이 영역 안의 Apps Script 업로더가 Google Drive로 직접 전송합니다. GitHub 페이지에서 Base64로 변환하지 않기 때문에 기존 방식보다 훨씬 가볍게 전송됩니다.
원본 화질 그대로 임시 Drive에 업로드한 뒤, 최종 제출 시 DOCX와 함께 메일 첨부로 전송합니다. 메일 발송이 성공하면 임시폴더는 자동으로 휴지통으로 이동하며, 제출하지 않은 임시파일도 24시간 후 자동 정리됩니다.
